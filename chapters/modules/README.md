# Future module chapters

The public-facing starter intentionally publishes only the course overview, draft calendar, and FAQs. For each instructional chapter, copy `../../_templates/module-template.qmd` here, rename it (for example `01_evidence_and_estimands.qmd`), complete it, and add it under the "Instructional Modules" part in `_quarto.yml`.
